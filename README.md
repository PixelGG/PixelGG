## System profile

Ich entwickle nicht nur Funktionen, sondern die Regeln, Grenzen und Betriebswege, durch die ein System langfristig verlässlich bleibt. Der Client beschreibt eine Absicht. Die Serverdomäne entscheidet. Audit und Telemetrie halten fest, was tatsächlich geschah.

  <tr>
